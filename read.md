# 🐍 Python Project

A beginner-friendly **Python Console Application** that demonstrates the use of core Python modules such as `datetime`, `math`, `random`, `csv`, and `os`.  
This project provides an interactive menu-driven interface to explore **date & time operations, mathematical calculations, randomization, file handling, and module exploration**.

---

## 📖 Features

### 1. Date and Time Operations
- Display current date and time
- Calculate difference between two dates
- Format dates in different styles
- Show current timestamp
- Countdown timer (basic implementation)

### 2. Mathematical Operations
- Basic calculator (addition, subtraction, multiplication, division)
- Factorial of a number
- Square root calculation
- Power function
- Area of a circle

### 3. Random Module
- Generate random numbers
- Simulate dice rolls
- Random choice from a list
- Shuffle items in a list

### 4. File Operations
- Create and write to a file
- Read from a file
- Append text to a file
- Search for a word inside a file
- Delete a file safely

### 5. Explore Module Attributes
- Explore available functions in `math`, `random`, and `datetime` modules

---

## 🛠️ Requirements
- Python 3.x  
- No external libraries required (uses only built-in modules)
